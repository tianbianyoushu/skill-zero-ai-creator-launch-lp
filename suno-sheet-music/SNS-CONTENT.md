## Reddit 投稿 3本

Reddit は「広告っぽい投稿」を嫌うので、**質問/共有形式** で自然に書きます。

### 📮 Reddit 1: `r/SunoAI`

**Title**: `I built a free tool that turns Suno AI songs into sheet music PDFs (piano + guitar)`

**Body**:
```
Hey Suno community,

I've been making songs with Suno for a few months and kept wishing I could actually *play* them on piano or guitar. Ear-transcribing everything takes forever, so I built a tool that does it automatically.

**What it does**
- Upload any audio file (MP3/WAV/M4A/OGG/FLAC/AAC, up to 50MB)
- It uses Spotify's basic-pitch ML model to detect notes
- LilyPond typesets the result as:
  - Piano grand staff (treble + bass clef)
  - Guitar standard notation + 6-string TAB
- Download as A4 PDF

**Caveats**
- Accuracy is best when the melody is clean; dense mixes lose fidelity
- It's not perfect — treat it as a draft you can edit
- All processing is server-side, files auto-delete after a while

Try it: https://ai-gakufu.com/ (free, no signup, currently JP UI but upload works the same)

Happy to hear feedback — especially if certain genres transcribe better/worse for you.
```

### 📮 Reddit 2: `r/WeAreTheMusicMakers`

**Title**: `Free tool: turn any MP3/WAV into a piano or guitar sheet music PDF (AI-based)`

**Body**:
```
I built this after getting tired of transcribing my own demos by ear. Thought I'd share in case it saves others some hours.

How it works: Spotify's open-source basic-pitch model turns audio → MIDI → LilyPond → PDF. The whole pipeline is automated so you just upload and wait ~2 minutes.

What you get:
- Piano grand staff
- Guitar standard + TAB

Where it shines: solo piano, single-instrument melodies, mid-tempo pop. Where it struggles: dense mixes, extreme tempos, heavy vocal processing.

Free, no account. https://ai-gakufu.com/

Feedback welcome — what genres/instruments do you wish worked better?
```

### 📮 Reddit 3: `r/musictheory`

**Title**: `How do modern AI models actually "read" audio into notation? (technical breakdown)`

**Body**:
```
I spent the last few weeks digging into the pipeline behind audio-to-score conversion and wrote up what I learned. Might be useful for others curious about it.

The short version:
1. Audio → CQT spectrogram (log-frequency representation matched to musical pitches)
2. CNN detects pitch/onset/offset per frame
3. Post-processing → MIDI (quantized to notes with start/end/pitch/velocity)
4. MIDI → LilyPond text → typeset PDF

Full breakdown with diagrams:
https://ai-gakufu.com/blog/how-ai-transcribes-music.html

I also built a free tool using this pipeline: https://ai-gakufu.com/

Curious if anyone here has tried training their own transcription models — would love to compare notes.
```

## 運用Tips

### フォロワー増のミニテク

1. **画像は必ず付ける** — 楽譜スクショ、処理画面、図解などで視覚情報を足す
2. **引用ツイート/コメント** — Suno AI公式・有名ユーザーのポストに関連コメントを付ける
3. **ハッシュタグは3〜5個** — 多すぎるとスパム判定
4. **返信は24時間以内** — エンゲージメント維持の最低条件

### 絶対にやってはいけないこと

- ❌ 自動ツールで大量フォロー
- ❌ 他人のコンテンツの無断転載
- ❌ 同じ投稿のコピペ連投（シャドウBAN）
- ❌ ハッシュタグ乱用（10個以上）
- ❌ アーティスト名・曲名を無断で使って「カバー」を名乗る

---

最後に。**SNS運用は短距離走ではなく長距離走** です。毎週少しずつ積み上げれば、3ヶ月後には確実に状況が変わっています。頑張ってください！
